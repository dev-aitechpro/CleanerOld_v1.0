3. Что должно было произойти — ожидаемое поведение
4. Скриншот (если возможно)
5. Версия Windows и версия .NET Framework
Предложения по улучшению
Идеи и предложения приветствуются. Создайте Issue с меткой enhancement. Запрос на добавление функциональности. Если хотите добавить новую функцию:

2. Получите обратную связь от разработчиков
3. Вносите изменения
Разработка

Подготовка окружения
1. Установите Visual Studio 2019/2022
   - Выберите компонент ".NET desktop development"
2. Установите .NET Framework 4.8
3. Клонируйте репозиторий:
   bash
   git clone https://github.com/dev-aitechpro/CleanerOld_v1.0.git
   
Процесс разработки
1. Сделайте форк репозитория
2. Создайте ветку для изменений:
   bash
   git checkout -b feature/your-feature
3. Внесите изменения
4. Проверьте сборку в Release:
   bash
   dotnet build -c Release
5. Зафиксируйте изменения:
   bash
   git add .
   git commit -m "Описание изменений"
   git push origin feature/your-feature
6. Создайте Pull Request

Стиль кода
- Используйте стандартные соглашения C(Microsoft)
- Комментируйте сложные участки кода
- Проверяйте, что приложение работает с правами администратора
- Тестируйте на Windows 10/11
